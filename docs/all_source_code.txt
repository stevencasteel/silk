SILK — MASTER ENGINEERING & ARCHITECTURE DOCUMENT
Nervous System & Component-System Pipeline Edition
Target Stack: React 19 + TypeScript 6 + Vite 8 + Babylon.js + Rapier 3D WASM
===============================================================================

1. EXECUTIVE SUMMARY & DESIGN PHILOSOPHY
-------------------------------------------------------------------------------
SILK is a vertical arena action game built around dynamic movement. To guarantee 
high frame-rate stability, prevent race conditions, and eliminate visual micro-stuttering 
on high-refresh-rate displays (144Hz+), the architecture strictly decouples 
subsystems into isolated layers orchestrated by a central SystemManager.

- React: Strictly for high-level viewport mounting and basic UI layout overlays.
- Babylon.js: Visual representation, render pass, and presentation state.
- Rapier WASM: Authoritative physics calculations, rigid bodies, and constraints.
- Gameplay Systems: Pure logic operating on decoupled data components.
- DOM HUD: Bypasses React Virtual DOM entirely, utilizing event-driven direct DOM 
  mutations to achieve ultra-lean, low-overhead UI synchronization.
- Dual-Buffer Interpolation: Decouples rendering frame rate from physics tick rate 
  by maintaining past and present transform buffers to interpolate position/rotation.

2. THE NERVOUS SYSTEM: FRAME EXECUTION PIPELINE
-------------------------------------------------------------------------------
The GameLoop enforces a strict, dual-layer sequential pipeline separating the fixed 
timestep update thread (dt = 1/60s) from the variable-rate render loop:

A. FIXED-TIMESTEP UPDATE (60Hz Ticks)
1. Input Phase: PlayerInputSystem polls DOM/Keyboard, writing inputs to the InputBuffer.
2. Simulation Phase: 
   - PlayerMovementSystem reads inputs and maps velocities directly to the authoritative 
     physics world via IWritablePhysics. It accelerates the player horizontally during 
     swings and adjusts the rope length during climbs.
   - WardenBrainSystem delegates update commands to the current Warden State Machine, 
     updating kinematic velocities and publishing state events through the EventBroker.
3. Physics Phase: RapierWorldSystem steps the physical WASM simulation.
   - It captures the physical coordinates of the previous frame and copies them 
     to previousTransform buffers.
   - It calculates physical swinging constraints, applying a kinematic pendulum-tension 
     solver that constrains the player coordinates to a sphere boundary around the anchor.
   - It resolves player coordinates against static platforms (represented by box bounds).
   - It steps the Rapier world simulation.
   - It pulls new translation/rotation data and writes to currentTransform buffers.
   - It calculates simulated rope tension and length, publishing updates.

B. VARIABLE-RATE RENDERING PASS (Variable FPS)
1. Render-Sync Phase: TransformSyncSystem matches entity transforms between the 
   authoritative physics layer (IReadablePhysics) and the active Babylon visuals 
   (IVisualRegistry) using Linear/Spherical interpolation:
     Position = Previous + (Current - Previous) * alpha
     Rotation = Slerp(Previous, Current, alpha)
2. Presentation Phase: RopeVisualizerSystem queries current/previous transforms and 
   regenerates a dynamic line ribbon, simulating rope sag under low tension values.
3. Camera Phase: CameraSystem targets a weighted focus center between the Player 
   and the Warden, applying spring-mass-damper physics and rotational screen shake.
4. Render Phase: RenderSystem draws the active Babylon WebGL call using interpolated nodes.
5. Audio Phase: AudioDirectorSystem and synthesizers handle real-time frequency/amplitude 
   scaling based on tension and velocity triggers.
6. UI Phase: DomHudSystem mutates DOM nodes reactively based on incoming events.

3. ARCHITECTURAL PATTERNS & SOLID COMPLIANCE
-------------------------------------------------------------------------------
- Single Responsibility Principle (SRP): Systems contain only execution logic, while 
  Components (PlayerData, WardenData) hold pure data. The rendering registry maps mesh 
  transforms without mixing structural physics logic.
- Open/Closed Principle (OCP): Warden AI utilizes a formal State Pattern (IWardenState). 
  Adding behavior structures (e.g., dynamic charges or dazed states) requires introducing 
  a new state file with zero changes to the WardenBrainSystem itself.
- Liskov Substitution Principle (LSP): SystemManager expects general ISystem structures. 
  Both synchronous and asynchronous initialization flows behave transparently.
- Interface Segregation Principle (ISP): Physics exposes distinct IReadablePhysics and 
  IWritablePhysics boundaries, restricting gameplay logic to necessary operations. 
  Mesh management uses IVisualRegistry to abstract away direct Babylon references.
- Dependency Inversion Principle (DIP): TransformSyncSystem and RopeVisualizerSystem 
  depend entirely on IReadablePhysics and IVisualRegistry interfaces. They have no 
  direct coupling to concrete rendering or physics engines.

import fs from 'fs';
import path from 'path';
import { fileURLToPath } from 'url';

const fsp = fs.promises;
const __filename = fileURLToPath(import.meta.url);
const __dirname = path.dirname(__filename);
const rootDir = path.resolve(__dirname, '..');
const docsDir = path.join(rootDir, 'docs');
const outputFile = path.join(docsDir, 'all_source_code.txt');

function shouldInclude(filePath) {
  const relPath = path.relative(rootDir, filePath).split(path.sep).join('/');
  
  if (
    path.basename(filePath) === 'all_source_code.txt' || 
    path.basename(filePath) === 'source_code_manifest.json' ||
    path.basename(filePath) === 'sourceCodeManifest.ts'
  ) {
    return false;
  }

  const ignoredPaths = ['node_modules', '.git', 'dist', '.vscode', '.github', 'BOX_BATTLE_ARCHIVE'];
  if (ignoredPaths.some(p => relPath.startsWith(p) || relPath.includes(`/${p}/`))) return false;
  
  const boilerplateConfigs = ['.DS_Store', 'package-lock.json', 'tsconfig.tsbuildinfo'];
  if (boilerplateConfigs.includes(path.basename(relPath))) return false;

  const ext = path.extname(relPath);
  const allowedExts = ['.ts', '.tsx', '.js', '.jsx', '.css', '.html', '.json', '.md', '.txt', '.glsl', '.command'];
  return allowedExts.includes(ext);
}

function getAllFiles(dir, fileList = []) {
  const files = fs.readdirSync(dir);
  for (const file of files) {
    const filePath = path.join(dir, file);
    const fileName = path.basename(filePath);
    if (fs.statSync(filePath).isDirectory()) {
      if (!fileName.startsWith('.') && fileName !== 'node_modules' && fileName !== 'dist') {
        getAllFiles(filePath, fileList);
      }
    } else {
      if (shouldInclude(filePath)) fileList.push(filePath);
    }
  }
  return fileList;
}

function generateTree(dir, prefix = '') {
  let output = '';
  const files = fs.readdirSync(dir);
  
  const items = files
    .map(file => {
      const filePath = path.join(dir, file);
      let isDir = false;
      try {
        isDir = fs.statSync(filePath).isDirectory();
      } catch (e) {}
      return { name: file, isDir, path: filePath };
    })
    .filter(item => {
      if (item.name.startsWith('.') && item.name !== '.env') return false;
      return true;
    })
    .sort((a, b) => {
      if (a.isDir && !b.isDir) return -1;
      if (!a.isDir && b.isDir) return 1;
      return a.name.localeCompare(b.name);
    });

  for (let i = 0; i < items.length; i++) {
    const item = items[i];
    const isLast = i === items.length - 1;
    const branch = isLast ? '└── ' : '├── ';
    
    const skippedDirs = ['node_modules', 'dist', '.git', 'BOX_BATTLE_ARCHIVE'];
    if (item.isDir && skippedDirs.includes(item.name)) {
      output += `${prefix}${branch}${item.name}/ (contents skipped)\n`;
      continue;
    }

    output += `${prefix}${branch}${item.name}${item.isDir ? '/' : ''}\n`;

    if (item.isDir) {
      const nextPrefix = prefix + (isLast ? '    ' : '│   ');
      output += generateTree(item.path, nextPrefix);
    }
  }
  return output;
}

async function main() {
  try {
    if (!fs.existsSync(docsDir)) {
      fs.mkdirSync(docsDir, { recursive: true });
    }

    const now = new Date().toLocaleString();
    let content = '┌──────────────────────────────────────────────────┐\n';
    content += '│                    PROJECT SILK                  │\n';
    content += '│               Vite + React + Babylon             │\n';
    content += '└──────────────────────────────────────────────────┘\n';
    content += ` [SYSTEM] Generated: ${now}\n`;
    content += ` [BASELINE]: React 19, TypeScript 6, Babylon.js, Rapier 3D, Tone.js\n\n`;
    
    content += '─── ABRIDGED DIRECTORY STRUCTURE ───────────────────\n';
    content += '.\n';
    content += generateTree(rootDir, '');
    content += '\n\n─── SOURCE FILES ───────────────────────────────────\n\n';

    const files = getAllFiles(rootDir);
    
    for (let i = 0; i < files.length; i++) {
      const filePath = files[i];
      const relPath = path.relative(rootDir, filePath).split(path.sep).join('/');
      
      content += `● ./${relPath}\n`;
      content += `────────────────────────────────────────────────────\n`;
      const fileContent = await fsp.readFile(filePath, 'utf8');
      content += fileContent + '\n\n\n';
    }

    await fsp.writeFile(outputFile, content, 'utf8');
    const publicOutputFile = path.join(rootDir, 'public', 'all_source_code.txt');
    await fsp.writeFile(publicOutputFile, content, 'utf8');
    
    console.log('Source context assembled successfully.');
    process.exit(0);

  } catch (err) {
    console.error('Error during context compilation:', err);
    process.exit(1);
  }
}

main();

const includeDirs = ['src'];

function scanDir(dir) {
  const entries = fs.readdirSync(dir, { withFileTypes: true });
  for (const entry of entries) {
    const fullPath = path.join(dir, entry.name);
    const relPath = path.relative(rootDir, fullPath).replace(/\\/g, '/');

    if (entry.isDirectory()) {
      if (entry.name !== 'node_modules' && entry.name !== 'dist' && entry.name !== '.git') {
        scanDir(fullPath);
      }
    } else if (entry.isFile()) {
      if (entry.name === 'sourceCodeManifest.ts' || entry.name === 'source_code_manifest.json') {
        continue;
      }
      const ext = path.extname(entry.name);
      if (['.ts', '.tsx', '.js', '.jsx', '.css', '.json', '.md', '.txt', '.html', '.glsl'].includes(ext)) {
        const content = fs.readFileSync(fullPath, 'utf8');
        manifest[relPath] = content;
      }
    }
  }
}

for (const file of includeFiles) {
  const fullPath = path.join(rootDir, file);
  if (fs.existsSync(fullPath)) {
    const content = fs.readFileSync(fullPath, 'utf8');
    manifest[file] = content;
  }
}

for (const dir of includeDirs) {
  const fullPath = path.join(rootDir, dir);
  if (fs.existsSync(fullPath)) {

  }
}

import * as Tone from "tone";

export class TensionSynthesizer {
  private fmOsc: Tone.FMOscillator | null = null;
  private lowpassFilter: Tone.Filter | null = null;
  private gainNode: Tone.Gain | null = null;
  private lfo: Tone.LFO | null = null;

  public initialize(): void {
    this.lowpassFilter = new Tone.Filter({
      frequency: 200,
      type: "lowpass",
      Q: 4.0
    }).toDestination();

    this.fmOsc = new Tone.FMOscillator({
      frequency: 55,
      type: "sawtooth",
      modulationType: "sine",
      harmonicity: 1.5,
      modulationIndex: 5
    });

    this.gainNode = new Tone.Gain(0.15);

    this.lfo = new Tone.LFO({
      frequency: 0.2,
      min: 150,
      max: 280
    });

    this.fmOsc.connect(this.gainNode);
    this.gainNode.connect(this.lowpassFilter);
    this.lfo.connect(this.lowpassFilter.frequency);

    this.lfo.start();
    this.fmOsc.start();
  }

  public updateDronePitch(tensionVal: number): void {
    if (!this.fmOsc || !this.gainNode || !this.lowpassFilter) return;

    const now = Tone.now();
    const clampedTension = Math.max(0, Math.min(1, tensionVal));

    const targetBaseFreq = 55 + clampedTension * 55;
    const targetModulationIndex = 5 + clampedTension * 25;
    const targetGain = 0.15 + clampedTension * 0.12;

    this.fmOsc.frequency.setTargetAtTime(targetBaseFreq, now, 0.1);
    this.fmOsc.modulationIndex.setTargetAtTime(targetModulationIndex, now, 0.1);
    this.gainNode.gain.setTargetAtTime(targetGain, now, 0.08);
  }

  public dispose(): void {
    if (this.fmOsc) {
      this.fmOsc.stop();
      this.fmOsc.dispose();
    }
    if (this.lfo) {
      this.lfo.stop();
      this.lfo.dispose();
    }
    if (this.lowpassFilter) {
      this.lowpassFilter.dispose();
    }
    if (this.gainNode) {
      this.gainNode.dispose();
    }
  }
}

import { ISystem } from "../../contracts/ISystem";
import { IReadablePhysics } from "../../contracts/IPhysicsWorld";
import { IVisualRegistry } from "../../contracts/IVisualRegistry";
import { EventBroker } from "../../core/events/EventBroker";
import { GameEvent } from "../../core/events/GameEvents";
import * as BABYLON from "@babylonjs/core";

export class CameraSystem implements ISystem {
    private cameraNode: BABYLON.FreeCamera | null = null;
    private shakeIntensity = 0.0;
    private shakeTimeRemaining = 0.0;
    private unsub: (() => void) | null = null;
    
    private currentTarget = new BABYLON.Vector3(0, 10, -25);
    private springPosition = new BABYLON.Vector3(0, 10, -25);
    private springVelocity = new BABYLON.Vector3(0, 0, 0);

    constructor(
        private physics: IReadablePhysics,
        private visualRegistry: IVisualRegistry,
        private broker: EventBroker
    ) {}

    public init(): void {
        const node = this.visualRegistry.getTransformNode("camera");
        if (node instanceof BABYLON.FreeCamera) {
            this.cameraNode = node;
            this.springPosition.copyFrom(node.position);
        }

        this.unsub = this.broker.subscribe(GameEvent.CAMERA_SHAKE_TRIGGERED, (payload) => {
            this.shakeIntensity = Math.max(this.shakeIntensity, payload.amplitude);
            this.shakeTimeRemaining = Math.max(this.shakeTimeRemaining, payload.duration);
        });
    }

    public update(dt: number): void {
        if (!this.cameraNode) {
            const node = this.visualRegistry.getTransformNode("camera");
            if (node instanceof BABYLON.FreeCamera) {
                this.cameraNode = node;
            }
            return;
        }

        const playerTrans = this.physics.getTransform("player");
        const wardenTrans = this.physics.getTransform("warden");

        if (playerTrans) {
            let focusX = playerTrans.x;
            let focusY = playerTrans.y;

            if (wardenTrans) {
                focusX = playerTrans.x * 0.7 + wardenTrans.x * 0.3;
                focusY = playerTrans.y * 0.7 + wardenTrans.y * 0.3;
            }

            this.currentTarget.set(focusX, focusY + 1.5, -24.0);
        }

        const stiffness = 8.0;
        const damping = 3.5;

        const forceX = (this.currentTarget.x - this.springPosition.x) * stiffness - this.springVelocity.x * damping;
        const forceY = (this.currentTarget.y - this.springPosition.y) * stiffness - this.springVelocity.y * damping;
        const forceZ = (this.currentTarget.z - this.springPosition.z) * stiffness - this.springVelocity.z * damping;

        this.springVelocity.x += forceX * dt;
        this.springVelocity.y += forceY * dt;
        this.springVelocity.z += forceZ * dt;

        this.springPosition.x += this.springVelocity.x * dt;
        this.springPosition.y += this.springVelocity.y * dt;
        this.springPosition.z += this.springVelocity.z * dt;

        this.cameraNode.position.copyFrom(this.springPosition);

        if (this.shakeTimeRemaining > 0) {
            this.shakeTimeRemaining -= dt;
            const currentIntensity = this.shakeIntensity * (this.shakeTimeRemaining / 0.5);

            if (currentIntensity > 0) {
                const shakeX = (Math.random() - 0.5) * currentIntensity * 2.5;
                const shakeY = (Math.random() - 0.5) * currentIntensity * 2.5;
                this.cameraNode.position.x += shakeX;
                this.cameraNode.position.y += shakeY;
            }
        } else {
            this.shakeIntensity = 0;
        }

        const targetLookAt = new BABYLON.Vector3(this.currentTarget.x, this.currentTarget.y, 0);
        this.cameraNode.setTarget(targetLookAt);
    }

    public dispose(): void {
        if (this.unsub) this.unsub();
    }
}

  private listeners: { [K in GameEvent]?: Set<EventCallback<any>> } = {};

  public subscribe<K extends GameEvent>(event: K, cb: EventCallback<GameEventMap[K]>): () => void {
    if (!this.listeners[event]) {
      this.listeners[event] = new Set();
    }
    this.listeners[event]!.add(cb);
    return () => {
      this.listeners[event]?.delete(cb);
    };
  }

  public publish<K extends GameEvent>(event: K, payload: GameEventMap[K]): void {
    const set = this.listeners[event];
    if (set) {
      set.forEach((cb) => cb(payload));
    }
  }

  public clear(): void {
    this.listeners = {};
  }
}

export class GameLoop {
  private isRunning: boolean = false;
  private lastTime: number = 0;
  private accumulator: number = 0;
  private readonly fixedStep: number = 1 / 60;
  private onUpdate: (dt: number) => void;
  private onRender: (interpolationAlpha: number) => void;
  private rafId: number | null = null;

  constructor(onUpdate: (dt: number) => void, onRender: (interpolationAlpha: number) => void) {
    this.onUpdate = onUpdate;
    this.onRender = onRender;
    if (typeof window !== "undefined") {
      document.addEventListener("visibilitychange", this.handleVisibilityChange);
    }
  }

  public start(): void {
    if (this.isRunning) return;
    this.isRunning = true;
    this.lastTime = performance.now();
    this.accumulator = 0;
    this.rafId = requestAnimationFrame((t) => this.tick(t));
  }

  public stop(): void {
    this.isRunning = false;
    if (this.rafId !== null) {
      cancelAnimationFrame(this.rafId);
      this.rafId = null;
    }
  }

  private tick(now: number): void {
    if (!this.isRunning) return;
    let dt = (now - this.lastTime) / 1000;
    this.lastTime = now;

    if (dt > 0.1) {
      dt = 0.1;
    }
    this.accumulator += dt;

    while (this.accumulator >= this.fixedStep) {
      this.onUpdate(this.fixedStep);
      this.accumulator -= this.fixedStep;
    }

    const alpha = this.accumulator / this.fixedStep;
    this.onRender(alpha);

    this.rafId = requestAnimationFrame((t) => this.tick(t));
  }

  private handleVisibilityChange = (): void => {
    if (document.hidden) {
      this.stop;
    } else {
      this.start();
    }
  };

  public cleanup(): void {
    this.stop();
    if (typeof window !== "undefined") {
      document.removeEventListener("visibilitychange", this.handleVisibilityChange);
    }
  }
}

    constructor(
        private playerData: PlayerData,
        private inputSystem: PlayerInputSystem,
        private physics: IWritablePhysics & { setRopeAttached(attached: boolean): void },
        private broker: EventBroker
    ) {}

    public update(dt: number): void {
        const input = this.inputSystem.inputBuffer;
        
        if (input.jump && !this.spaceWasPressed) {
            this.playerData.isRopeAttached = !this.playerData.isRopeAttached;
            this.physics.setRopeAttached(this.playerData.isRopeAttached);

                );

export class RopeVisualizerSystem implements ISystem {

    private initialized = false;

    constructor(
        private physics: IReadablePhysics,
        private visualRegistry: IVisualRegistry
    ) {}

    public init(): void {
        const scene = this.visualRegistry.getScene();
        if (!scene) return;

        const dummyPoints = [BABYLON.Vector3.Zero(), BABYLON.Vector3.Zero()];
        this.ropeMesh = BABYLON.MeshBuilder.CreateLines("tetherLine", {
            points: dummyPoints,
            updatable: true
        }, scene);

        this.ropeMesh.color = new BABYLON.Color3(0.1, 0.6, 0.9);
        this.initialized = true;
    }

    public update(dt: number): void {
    }

    public render(alpha: number): void {
        if (!this.initialized || !this.ropeMesh) return;

        const anchor = this.physics.getAnchorPosition();
        const playerTrans = this.physics.getTransform("player");
        const playerPrev = this.physics.getPreviousTransform("player");

        if (anchor && playerTrans && playerPrev) {
            const px = playerPrev.x + (playerTrans.x - playerPrev.x) * alpha;
            const py = playerPrev.y + (playerTrans.y - playerPrev.y) * alpha;
            const pz = playerPrev.z + (playerTrans.z - playerPrev.z) * alpha;

            const playerPos = new BABYLON.Vector3(px, py, pz);
            const anchorPos = new BABYLON.Vector3(anchor.x, anchor.y, anchor.z);

            const tensionVal = this.physics.getRopeLength() / this.physics.getRopeMaxLength();
            const clampedTension = Math.max(0, Math.min(1, tensionVal));

            const segments = 12;
            const points: BABYLON.Vector3[] = [];

            for (let i = 0; i <= segments; i++) {
                const ratio = i / segments;
                const p = BABYLON.Vector3.Lerp(anchorPos, playerPos, ratio);

                if (clampedTension < 0.95) {
                    const sag = Math.sin(ratio * Math.PI) * (1.0 - clampedTension) * 1.5;
                    p.y -= sag;
                }
                points.push(p);
            }

            this.ropeMesh = BABYLON.MeshBuilder.CreateLines("tetherLine", {
                points: points,
                instance: this.ropeMesh
            });
        }
    }

    public dispose(): void {
        if (this.ropeMesh) {
            this.ropeMesh.dispose();
        }
    }

        { minX: -15.0, maxX: -7.0, minY: 11.5, maxY: 12.5 },
        { minX: 7.0, maxX: 15.0, minY: 17.5, maxY: 18.5 }
    ];

    constructor(private broker: EventBroker) {}

    public async init(): Promise<void> {
        try {
            this.RAPIER = await import("@dimforge/rapier3d");
            
            if (this.RAPIER && typeof this.RAPIER.init === "function") {
                await this.RAPIER.init();
            }

            const gravity = { x: 0, y: -9.81, z: 0 };
            this.world = new this.RAPIER.World(gravity);

            const playerBodyDesc = this.RAPIER.RigidBodyDesc.kinematicPositionBased();
            playerBodyDesc.setTranslation(0, 10, 0);
            const playerBody = this.world.createRigidBody(playerBodyDesc);
            this.rigidBodies.set("player", playerBody);

            const playerColliderDesc = this.RAPIER.ColliderDesc.cuboid(0.5, 1.0, 0.5);
            this.world.createCollider(playerColliderDesc, playerBody);

            const wardenBodyDesc = this.RAPIER.RigidBodyDesc.kinematicPositionBased();
            wardenBodyDesc.setTranslation(5, 5, 0);
            const wardenBody = this.world.createRigidBody(wardenBodyDesc);
            this.rigidBodies.set("warden", wardenBody);

            const wardenColliderDesc = this.RAPIER.ColliderDesc.cuboid(1.0, 1.0, 1.0);
            this.world.createCollider(wardenColliderDesc, wardenBody);

            this.currentTransforms.set("player", { x: 0, y: 10, z: 0, qx: 0, qy: 0, qz: 0, qw: 1 });
            this.currentTransforms.set("warden", { x: 5, y: 5, z: 0, qx: 0, qy: 0, qz: 0, qw: 1 });
            this.snapTransforms();
        } catch (err) {
            console.warn("Failed to initialize Rapier WASM, running fallback virtual physics engine.", err);
            this.currentTransforms.set("player", { x: 0, y: 10, z: 0, qx: 0, qy: 0, qz: 0, qw: 1 });
            this.currentTransforms.set("warden", { x: 5, y: 5, z: 0, qx: 0, qy: 0, qz: 0, qw: 1 });
            this.snapTransforms();
        }
    }

    private snapTransforms(): void {
        this.previousTransforms.clear();
        for (const [key, value] of this.currentTransforms.entries()) {
            this.previousTransforms.set(key, { ...value });
        }

        if (this.world) {
            for (const [id, body] of this.rigidBodies.entries()) {
                const translation = body.translation();
                const rotation = body.rotation();
                this.currentTransforms.set(id, {
                    x: translation.x,
                    y: translation.y,
                    z: translation.z,
                    qx: rotation.x,
                    qy: rotation.y,
                    qz: rotation.z,
                    qw: rotation.w
                });
            }
        } else {
            for (const [id, current] of this.currentTransforms.entries()) {
                const velocity = this.velocities.get(id) || { x: 0, y: 0, z: 0 };
                const updated = {
                    x: current.x + velocity.x * (1 / 60),
                    y: current.y + velocity.y * (1 / 60),
                    z: current.z + velocity.z * (1 / 60),
                    qx: current.qx,
                    qy: current.qy,
                    qz: current.qz,
                    qw: current.qw
                };
                this.currentTransforms.set(id, updated);
            }
        }
    }

    public update(dt: number): void {
        this.snapTransforms();

        const playerBody = this.rigidBodies.get("player");
        const currentPos = playerBody ? playerBody.translation() : this.currentTransforms.get("player")!;

        let nextX = currentPos.x;
        let nextY = currentPos.y;
        let nextZ = 0;

        if (this.isRopeAttached) {
            this.playerDynamicVel.y += -12.0 * dt;

            const inputVel = this.velocities.get("player") || { x: 0, y: 0, z: 0 };
            this.playerDynamicVel.x += inputVel.x * 2.5 * dt;

            this.playerDynamicVel.x *= Math.pow(0.985, dt * 60);
            this.playerDynamicVel.y *= Math.pow(0.985, dt * 60);

            nextX += this.playerDynamicVel.x * dt;
            nextY += this.playerDynamicVel.y * dt;

            const dx = nextX - this.anchor.x;
            const dy = nextY - this.anchor.y;
            const dist = Math.sqrt(dx * dx + dy * dy);

            if (dist > this.ropeMaxLength) {
                const nx = dx / dist;
                const ny = dy / dist;

                nextX = this.anchor.x + nx * this.ropeMaxLength;
                nextY = this.anchor.y + ny * this.ropeMaxLength;

                const dot = this.playerDynamicVel.x * nx + this.playerDynamicVel.y * ny;
                if (dot > 0) {
                    this.playerDynamicVel.x -= dot * nx;
                    this.playerDynamicVel.y -= dot * ny;
                }
            }
        } else {
            const inputVel = this.velocities.get("player") || { x: 0, y: 0, z: 0 };
            this.playerDynamicVel.x = inputVel.x;
            this.playerDynamicVel.y = inputVel.y;

            nextX += this.playerDynamicVel.x * dt;
            nextY += this.playerDynamicVel.y * dt;
        }

        const playerHalfW = 0.5;
        const playerHalfH = 1.0;

        for (const plat of this.platforms) {
            const overlapX = (nextX + playerHalfW > plat.minX) && (nextX - playerHalfW < plat.maxX);
            const overlapY = (nextY + playerHalfH > plat.minY) && (nextY - playerHalfH < plat.maxY);
            if (overlapX && overlapY) {
                const overlapDepthX = Math.min(nextX + playerHalfW - plat.minX, plat.maxX - (nextX - playerHalfW));
                const overlapDepthY = Math.min(nextY + playerHalfH - plat.minY, plat.maxY - (nextY - playerHalfH));
                
                if (overlapDepthY < overlapDepthX) {
                    if (nextY > (plat.minY + plat.maxY) / 2) {
                        nextY = plat.maxY + playerHalfH;
                        if (this.playerDynamicVel.y < 0) this.playerDynamicVel.y = 0;
                    } else {
                        nextY = plat.minY - playerHalfH;
                        if (this.playerDynamicVel.y > 0) this.playerDynamicVel.y = 0;
                    }
                } else {
                    if (nextX > (plat.minX + plat.maxX) / 2) {
                        nextX = plat.maxX + playerHalfW;
                        this.playerDynamicVel.x = 0;
                    } else {
                        nextX = plat.minX - playerHalfW;
                        this.playerDynamicVel.x = 0;
                    }
                }
            }
        }

        const borderX = 14.0;
        if (nextX < -borderX) {
            nextX = -borderX;
            this.playerDynamicVel.x = 0;
        }
        if (nextX > borderX) {
            nextX = borderX;
            this.playerDynamicVel.x = 0;
        }
        if (nextY < 1.0) {
            nextY = 1.0;
            this.playerDynamicVel.y = 0;
        }
        if (nextY > 28.0) {
            nextY = 28.0;
            this.playerDynamicVel.y = 0;
        }

        if (playerBody) {
            playerBody.setNextKinematicTranslation({ x: nextX, y: nextY, z: nextZ });
        } else {
            this.currentTransforms.set("player", {
                x: nextX,
                y: nextY,
                z: nextZ,
                qx: 0,
                qy: 0,
                qz: 0,
                qw: 1
            });
        }

        const wardenVel = this.velocities.get("warden") || { x: 0, y: 0, z: 0 };
        const wardenBody = this.rigidBodies.get("warden");
        if (wardenBody) {
            wardenBody.setNextKinematicTranslation({
                x: wardenBody.translation().x + wardenVel.x * dt,
                y: wardenBody.translation().y + wardenVel.y * dt,
                z: wardenBody.translation().z + wardenVel.z * dt
            });
        }

        if (this.world) {
            this.world.step();
        }

        const dx = nextX - this.anchor.x;
        const dy = nextY - this.anchor.y;
        const currentDist = Math.sqrt(dx * dx + dy * dy);
        const tension = Math.max(0, Math.min(1, currentDist / this.ropeMaxLength));

        this.broker.publish(GameEvent.ROPE_TENSION_CHANGE, { tension });
        this.broker.publish(GameEvent.ROPE_LENGTH_CHANGE, { length: currentDist, maxLength: this.ropeMaxLength });
    }

    public getTransform(entityId: string): PhysicsTransform | null {
        return this.currentTransforms.get(entityId) || null;
    }

    public getPreviousTransform(entityId: string): PhysicsTransform | null {
        return this.previousTransforms.get(entityId) || null;
    }

    public getAnchorPosition(): { x: number; y: number; z: number } | null {
        return this.anchor;
    }

    public getRopeLength(): number {
        const playerTrans = this.getTransform("player");
        if (!playerTrans) return 0;
        const dx = playerTrans.x - this.anchor.x;
        const dy = playerTrans.y - this.anchor.y;
        return Math.sqrt(dx * dx + dy * dy);
    }

    public getRopeMaxLength(): number {
        return this.ropeMaxLength;
    }

    public applyImpulse(entityId: string, x: number, y: number, z: number): void {
        if (entityId === "player") {
            this.playerDynamicVel.x += x;
            this.playerDynamicVel.y += y;
        } else if (this.world) {
            const body = this.rigidBodies.get(entityId);
            if (body && typeof body.applyImpulse === "function") {
                body.applyImpulse({ x, y, z }, true);
            }
        }
    }

    public setKinematicVelocity(entityId: string, x: number, y: number, z: number): void {
        this.velocities.set(entityId, { x, y, z });
    }

    public setRopeMaxLength(length: number): void {
        this.ropeMaxLength = length;
    }

    public setRopeAttached(attached: boolean): void {
        this.isRopeAttached = attached;
    }
}

import { ISystem } from "../../contracts/ISystem";
import { IReadablePhysics } from "../../contracts/IPhysicsWorld";
import { IVisualRegistry } from "../../contracts/IVisualRegistry";
import * as BABYLON from "@babylonjs/core";

export class TransformSyncSystem implements ISystem {
    constructor(
        private physics: IReadablePhysics,
        private visualRegistry: IVisualRegistry
    ) {}

    public update(dt: number): void {
        // High refresh rate synchronization happens in render()
    }

    public render(alpha: number): void {
        this.syncEntity("player", alpha);
        this.syncEntity("warden", alpha);
    }

    private syncEntity(entityId: string, alpha: number): void {
        const node = this.visualRegistry.getTransformNode(entityId);
        if (!node) return;

        const current = this.physics.getTransform(entityId);
        const previous = this.physics.getPreviousTransform(entityId);

        if (current && previous) {
            node.position.x = previous.x + (current.x - previous.x) * alpha;
            node.position.y = previous.y + (current.y - previous.y) * alpha;
            node.position.z = previous.z + (current.z - previous.z) * alpha;

            const prevQuat = new BABYLON.Quaternion(previous.qx, previous.qy, previous.qz, previous.qw);
            const currQuat = new BABYLON.Quaternion(current.qx, current.qy, current.qz, current.qw);
            
            if (!node.rotationQuaternion) {
                node.rotationQuaternion = new BABYLON.Quaternion();
            }
            BABYLON.Quaternion.SlerpToRef(prevQuat, currQuat, alpha, node.rotationQuaternion);
        } else if (current) {
            node.position.set(current.x, current.y, current.z);
            if (!node.rotationQuaternion) {
                node.rotationQuaternion = new BABYLON.Quaternion();
            }
            node.rotationQuaternion.set(current.qx, current.qy, current.qz, current.qw);
        }
    }
}

export class DomHudSystem implements ISystem {

    private tensionText: HTMLElement | null = null;
    private speedBar: HTMLElement | null = null;
    private speedText: HTMLElement | null = null;
    private hpText: HTMLElement | null = null;
    private hpValue: HTMLElement | null = null;
    private bossStateText: HTMLElement | null = null;
    private bossPhaseText: HTMLElement | null = null;

    constructor(private broker: EventBroker) {}

    public init(): void {
        this.cacheDomElements();
        this.registerSubscribers();
    }

    public update(dt: number): void {
        // DOM mutations are event-driven
    }

    private cacheDomElements(): void {
        if (typeof document === "undefined") return;
        this.tensionBar = document.getElementById("tension-meter-bar");
        this.tensionText = document.getElementById("tension-meter-text");
        this.speedBar = document.getElementById("speedometer-bar");
        this.speedText = document.getElementById("speedometer-text");
        this.hpText = document.getElementById("player-hp-bar");
        this.hpValue = document.getElementById("player-hp-value");
        this.bossStateText = document.getElementById("boss-state-text");
        this.bossPhaseText = document.getElementById("boss-state-phase");
    }

    private registerSubscribers(): void {
        this.unsubscribes.push(
            this.broker.subscribe(GameEvent.ROPE_TENSION_CHANGE, (payload) => this.updateTensionDisplay(payload.tension))
        );
        this.unsubscribes.push(
            this.broker.subscribe(GameEvent.PLAYER_VELOCITY_CHANGED, (payload) => this.updateVelocityDisplay(payload.velocity, payload.maxVelocity))
        );
        this.unsubscribes.push(
            this.broker.subscribe(GameEvent.PLAYER_HEALTH_CHANGED, (payload) => this.updateHealthDisplay(payload.hp, payload.maxHp))
        );
        this.unsubscribes.push(
            this.broker.subscribe(GameEvent.WARDEN_STATE_CHANGE, (payload) => this.updateWardenStateDisplay(payload.state, payload.hue))
        );
    }

    private updateTensionDisplay(value: number): void {
        const clamped = Math.max(0, Math.min(1, value));
        const percentage = (clamped * 100).toFixed(1) + "%";
        if (this.tensionBar) {
            this.tensionBar.style.width = percentage;
            if (clamped > 0.8) this.tensionBar.style.backgroundColor = "var(--signal-red, #ef4444)";
            else if (clamped > 0.5) this.tensionBar.style.backgroundColor = "var(--signal-yellow, #eab308)";
            else this.tensionBar.style.backgroundColor = "var(--signal-green, #22c55e)";
        }
        if (this.tensionText) this.tensionText.textContent = `TENSION: ${percentage}`;
    }

    private updateVelocityDisplay(velocity: number, maxVelocity: number): void {
        const ratio = maxVelocity > 0 ? Math.max(0, Math.min(1, velocity / maxVelocity)) : 0;
        const percentage = (ratio * 100).toFixed(0) + "%";
        if (this.speedBar) this.speedBar.style.width = percentage;
        if (this.speedText) this.speedText.textContent = `VELOCITY: ${velocity.toFixed(0)} / ${maxVelocity.toFixed(0)} m/s`;
    }

    private updateHealthDisplay(hp: number, maxHp: number): void {
        if (this.hpValue) this.hpValue.textContent = `HP: ${hp} / ${maxHp}`;
        if (this.hpText) {
            const hpPct = ((hp / maxHp) * 100).toFixed(0) + "%";
            this.hpText.style.width = hpPct;
            this.hpText.style.backgroundColor = hp <= 1 ? "var(--signal-red, #ef4444)" : "var(--signal-green, #22c55e)";
        }
    }

    private updateWardenStateDisplay(state: string, hue: string): void {
        if (this.bossStateText) {
            this.bossStateText.textContent = `WARDEN: ${state.toUpperCase()}`;
            this.bossStateText.style.color = hue;
        }
        if (this.bossPhaseText) {
            this.bossPhaseText.style.borderColor = hue;
            this.bossPhaseText.style.color = hue;
        }
    }

    public dispose(): void {
        this.unsubscribes.forEach((unsub) => unsub());
        this.unsubscribes = [];
    }
}
